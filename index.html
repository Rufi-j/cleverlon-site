Questions we hear

Access is limited by role and changes are logged. Before we build, we agree a data plan with you. We sign a data processing agreement if you need one.

You own your data. For custom software, you own the code once the project is paid in full. If you cancel an automation's monthly plan, we hand over the workflow files and documentation.

Automations have a one-off setup fee, from $800 to $2,500, and a monthly fee, from $150 to $400. The first month is included in the setup fee. Campaigns start at $800. Custom software is quoted per project after a free scoping call. There is no lock-in: if you cancel, we hand over the workflow files and documentation.

How long does it take?

Automations go live in 10 to 14 days. A campaign takes about 2 weeks. For custom software we set a timeline when we scope the project.

What happens after launch?

The monthly fee covers hosting, monitoring and changes. For custom software, we stay on for changes after we deploy it.

We work in West Africa Time (UTC+1), which overlaps fully with UK and European working hours and with US mornings. We reply within one working day.
